# Simulation of PI Controller Parameter Optimization for an Inverted Pendulum Using Artificial Bee Colony (ABC)

## Overview
This project presents a Python-based simulation of an inverted pendulum system controlled by a Proportional–Integral (PI) controller whose parameters are optimized using the Artificial Bee Colony (ABC) algorithm. Instead of manually tuning the controller gains, the ABC optimization algorithm automatically searches for the optimal proportional gain (Kp) and integral gain (Ki) that minimize the pendulum angle error. The optimized controller is then used to stabilize the inverted pendulum, while the system response is visualized through an animation.

## Features
- Mathematical simulation of an inverted pendulum
- PI controller implementation
- Automatic tuning of Kp and Ki using Artificial Bee Colony
- Random initial disturbance generation
- Cost function based on accumulated squared angle error
- Convergence graph of optimization process
- Real-time animation of inverted pendulum motion

## Mathematical Model
The dynamics of the inverted pendulum are modeled using the rotational equation of motion:

$$
I\ddot{\theta} = \tau - mgl\sin(\theta) - c\dot{\theta}
$$

or equivalently,

$$
\ddot{\theta} =
\frac{\tau - mgl\sin(\theta) - c\dot{\theta}}{I}
$$

where

- $\theta$ : pendulum angle (rad)
- $\dot{\theta}$ : angular velocity (rad/s)
- $\ddot{\theta}$ : angular acceleration (rad/s²)
- $\tau$ : control torque generated by the PI controller (N·m)
- $m$ : pendulum mass (kg)
- $g$ : gravitational acceleration (9.81 m/s²)
- $l$ : pendulum length (m)
- $c$ : damping coefficient
- $I$ : pendulum moment of inertia (kg·m²)

> ### PI Controller <a name = 'PI'></a>
$$
u(t)=Kp​e(t)+Ki​∫e(t)dt
$$

The PI controller computes the control torque based on
- proportional error
- accumulated integral error

The objective is to drive the pendulum angle toward zero radians.

> ### Artificial Bee Colony Optimization <a name = 'ABC'></a>
Each food source represents one candidate solution [Kp, Ki]. The quality of each candidate is evaluated using the cost function obtained from the pendulum simulation. During every iteration, candidate solutions are updated and compared. Better solutions replace inferior ones until the maximum number of iterations is reached.

$$

The optimization minimizes the accumulated squared angular error throughout the simulation.
